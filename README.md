# Bike-Sharing-Analysis

## Deskripsi
Dashboard analisis data peminjaman sepeda menggunakan dataset Bike Sharing yang mencakup data periode 2011-2012.

## Cara Menjalankan Dashboard
1. Install library yang diperlukan
2. semua library sudah berada di requirements.txt, jalankan "pip install -r requirements.txt" di terminal
3. jalankan streamlit, "streamlit run dashboard.py"
